Help center

Everything you need to create, share, and manage a Wi-Fi QR code.

:book-open: Create a QR code

Open Wi-Fi QR codes and select Create QR code. Give the code a name you’ll recognize, enter the exact Wi-Fi network name, and choose your network security type. Enter the Wi-Fi password for secured networks.

:book-open: Share your code

Open a code and download the PNG for a sign, invitation, or guest instructions. You can also copy its scan link. In the live service, scans go through ShareWiFiQR before opening the guest page with your current Wi-Fi details. This demo generates preview codes for the planned scan route.

:book-open: Update your Wi-Fi details

Select a code and choose Edit network. Update the network name, password, or security type and save. The QR code keeps the same link so people can use the same printed code.

:book-open: Understand scan activity

The dashboard totals scans across your codes. Open an individual code to see its scan activity. Scans count visits to the link, including repeat visits. The demo displays sample activity.
